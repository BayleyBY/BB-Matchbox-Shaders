# BB_RetroHUD v1.0

Autodesk Flame Matchbox shader. Retro sci-fi HUD overlay inspired by Alien, Aliens, Blade Runner, 2001: A Space Odyssey and TRON.
Files: `BB_RetroHUD.1.glsl`, `BB_RetroHUD.2.glsl` + `BB_RetroHUD.xml`

---

## Why use this?

Build retro and analog sci-fi HUD graphics — Alien, Blade Runner, 2001, TRON territory — directly in Flame, complete with a CRT/old-TV pass for authentic scanline grunge. Use it for period-correct interfaces and monitor inserts without a motion-graphics round-trip or chasing down vintage screen elements.

---

## What It Does

Two-pass. Pass 1 draws 13 independently controllable animated HUD elements on a black background; pass 2 applies a CRT / old-TV filter for an authentic vintage-screen look.
